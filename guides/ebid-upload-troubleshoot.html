电子标上传失败、CA 锁识别不到、签章失败怎么排查

工程投标实战指南 · 第 14 篇

电子标最让人崩溃的，不是文件不会做，而是开标当天传不上去：控件装不上、CA 锁读不到证书、签章一直报错、文件超大小被拒、解密超时。这些问题共同的特点是——它们几乎都不发生在「做文件」阶段，而发生在最后两小时。

排查要有顺序，不要乱试。按「环境层 → 文件层 → 平台层」三层定位，能在大多数情况下几分钟内找到症结。

一、环境层：先确认「是电脑的问题还是文件的问题」

判断方法很简单：换一台电脑试一次。同一份文件在另一台电脑能传，问题就在环境；都传不了，问题在文件或平台。

症状优先排查处理顺序
CA 锁插上没反应USB 口 / 驱动 / 锁本身换后置 USB 口 → 换电脑 → reinstall 官方驱动 → 联系发证机构
能读证书但平台提示未检测到浏览器与控件用平台指定浏览器与版本 → 以管理员身份运行 → 重装控件/助手 → 清缓存重开
签章时报错或无响应证书有效期 / 签章控件 / 系统时间校核系统日期时间 → 查证书是否在有效期 → 重装签章控件 → 换电脑
页面卡住、按钮点不动浏览器兼容与缓存换指定浏览器 → 关拦截插件 → 清理缓存 → 换电脑
最容易被忽略的一条：系统时间不对会导致签章/证书校验失败。时区、日期差一天，证书可能被判「尚未生效」或「已过期」。

二、文件层：格式、大小、命名、内容

  • 格式：按平台要求（PDF / 加密 PDF / 特定封装格式），不要凭经验交 Word 版。
  • 大小：超限先查上限值，再压缩。图片型 PDF 优先做灰度或二值化压缩、扫描件按可读的最低分辨率重扫；压缩后必须重新打开逐页看一遍清晰度。
  • 命名：按平台规则（项目名称 + 标段 + 投标人 + 文件类型），不用空格和特殊符号，避免中文乱码。
  • 内容：内嵌字体缺失、超链接失效、书签层级错乱，都可能让签章或校验失败；另存为时保留嵌入字体。
  • 加密与权限：部分平台要求先加密再签章，操作顺序反了会报「文件已被修改」。

三、平台层：时间、回执、解密

  • 截止时间以上传完成并拿到回执为准，不是以「点开始上传」为准。大文件预留充足时间，避免踩点。
  • 上传成功要留存证据：回执编号、成功页面截图、时间。出现争议时这是唯一凭据。
  • 解密：在规定时段内用投标时同一把 CA 锁解密，锁不在手、证书过期、超时都会导致解密失败。
  • 撤回与重新上传：多数平台在截止前允许撤回重传，但要重新走签盖与加密流程，时间要留够。

四、8 个高频故障的处理顺序

1. CA 锁读不到：换口 → 换机 → 装驱动 → 查证书有效期 → 联系发证机构。
2. 控件装不上：确认浏览器版本合规 → 关安全软件 → 管理员权限安装 → 换机。
3. 签章报错：校系统时间 → 查证书有效期 → 重装签章控件 → 换机。
4. 文件超限：确认上限 → 压缩图片/重扫 → 分页拆分（若允许）→ 复核清晰度。
5. 上传中断：换网络（有线优先）→ 避开高峰期 → 提前完成，不踩点。
6. 提示文件被修改：按「先加密后签章」或平台规定顺序重做。
7. 页面异常：换指定浏览器 → 清缓存 → 关插件 → 换机。
8. 解密失败：确认同一把锁 → 确认在规定时段 → 立即联系平台与代理并留存记录。

五、开标前一天的极简演练

真正管用的不是临时抱佛脚，而是提前完整走一遍：

  • 用最终版文件，在开标当天要用的那台电脑、那个网络环境下，完整走一遍「加密 → 签章 → 上传 → 拿回执」。
  • 把 CA 锁、驱动安装包、备份电脑、备用网络（手机热点）放在一起。
  • 留一份未加密的可编辑源文件，出问题能立刻重做。
  • 记录平台技术支持电话与开标代理联系方式，出问题第一时间联系并留痕。

常见问题

CA 锁插上没反应，第一步该查什么？
先分层：换 USB 口（优先机箱后置口）、换电脑、换数据线，确认是锁本身还是驱动与浏览器环境问题；再看客户端能否读到证书信息。能读证书但平台识别不到，多半是浏览器或控件问题；完全读不到，多半是驱动或硬件问题。

文件总提示格式或大小不对，怎么压？
先确认平台要求的格式与大小上限，再决定压缩方式：扫描件用合适的分辨率与压缩方式而不是一味降低清晰度，图片型 PDF 优先灰度或二值化压缩，可编辑文档只保留必要的嵌入图片。压缩完必须重新打开确认可读。

开标解密提示失败，还能补救吗？
多数平台在规定时间内允许重新解密，也有明确的超时规则。第一时间联系平台技术人员与招标代理并留存记录，同时在时限内重试。是否补救以平台规则和代理答复为准，不要自行放弃。

本文只讲电子标操作环节的常见问题与自查方法，不涉及代投标、代签章等违规操作。各省市公共资源交易平台在浏览器版本、控件、加密签章流程、解密时限上规定不同，一切以本项目所在平台的官方说明与招标代理的答复为准。
